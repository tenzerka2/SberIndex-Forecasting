## Статус на 7 октября 2026

Расчёт всех трёх вариантов настоящего Prophet успешно выполнен на сервере GitHub Actions, без Colab и пользовательского Mac. Проверяемая версия исходников: `81e49b355f2a745fbeeb30eb091362a2f199a108`. [Ход и результаты запуска](https://github.com/tenzerka2/SberIndex-Forecasting/actions/runs/37579679215), [итоговая таблица и ограничения](VERIFIED_PROPHET_RESULTS.md).

Сравнение использует фиксированные 100 муниципалитетов, seed=0, три варианта Prophet, 11 дат обучения и 2400 оцениваемых пар для каждого варианта. Это 3300 отдельных обучений Prophet в трёх параллельных задачах. Выборка одинакова у всех моделей. Таблица на всех 2016 рядах ниже — отдельный эксперимент без Prophet; смешивать его числа с выборкой 100 нельзя.

## Воспроизведение без Colab

Подготовленные входы входят в `data/benchmark/`. Загрузка пяти CSV вручную для этого сравнения не нужна. Manifest содержит хеши исходных выгрузок, подготовленный пакет проверяется по SHA-256. В нём муниципальные наблюдения совпадают с исходным CSV; национальные значения проверены с учётом точности JSON.

```bash
python -m pip install -r requirements-prophet-verified.txt
python benchmarks/contest_prophet.py --prepared data/benchmark --sample 100 --workers 2 --output outputs/prophet_repeat
```

Файл зависимостей фиксирует четыре непосредственные версии из выполненного запуска; транзитивные зависимости не зафиксированы. В Actions используется Python 3.11. Режим `--resume` продолжает совместимый расчёт по сохранённым прогнозам каждого обучения; несовместимые данные, исходники и параметры отклоняются. В журнале выводится прогресс. `--skip-prophet` сохраняет только диагностику в `without_prophet` и не является сравнением с Prophet.

Для отдельных вариантов: `--variants auto`, `--variants log_fourier4` или `--variants log_month_dummies`. Их скачанные артефакты объединяются с проверкой одинаковых пар:

```bash
python benchmarks/summarize_prophet_ci.py outputs/ci_artifacts/prophet-auto/with_prophet outputs/ci_artifacts/prophet-log_fourier4/with_prophet outputs/ci_artifacts/prophet-log_month_dummies/with_prophet --output outputs/prophet_verified
```

На полном наборе `--sample 0` потребуется 66528 обучений для трёх вариантов; такой запуск не заявляется выполненным. Ноутбук в `notebooks/` оставлен как альтернативный интерфейс, а не обязательный путь запуска. Репозиторий закрытый, поэтому публичная ссылка Colab не обеспечивает доступ к нему.

## Как устроено сравнение

История: январь 2023 — декабрь 2024. Фиксированная случайная выборка (seed 0) совпадает у всех моделей. Наши панельные модели используют доступную на дату прогноза историю всех 2016 рядов; Prophet обучается отдельно на каждом оцениваемом ряду. Это сравнение подходов с разным использованием поперечной информации, а не одинакового набора признаков. Каждая модель видит только историю по дату origin включительно; национальные данные также обрезаются по месяцу наблюдения. Проверяются целевые месяцы, для которых есть фактические значения. Последующее уточнение публикаций не исключено: исходники — текущая выгрузка, не исторические версии данных. Отбор полных рядов использует ретроспективную доступность данных.

Три заранее заданных варианта Prophet: автоматическая годовая сезонность на исходных значениях; логарифм + годовой Fourier порядка 4; логарифм + 11 индикаторов месяца с декабрём в качестве опорного месяца. У двух последних changepoint_prior_scale=0.01; у месячных регрессоров prior_scale=0.1. Недельная и дневная сезонность отключены, прогнозы строятся только на начало месяца. Настройки сохраняются в JSON и исходном коде, версии пакетов и хеши — в manifest. Все варианты публикуются; лучший вариант не выбирается задним числом по тесту. Отрицательные прогнозы расходов ограничиваются нулём для всех моделей. Метрика R² считается по уровням расходов, не по темпам роста.

Рекомендация месячных прогнозов и месячных индикаторов: [официальная документация Prophet](https://facebook.github.io/prophet/docs/non-daily_data.html#monthly-data). Автоматический вариант с короткой историей может не включать годовую сезонность, поэтому сравнение не ограничивается только им.

| Горизонт | Даты прогноза | Число дат | Особенность |
|---|---|---:|---|
| 1 месяц | февраль–ноябрь 2024 | 10 | минимум 14 месяцев истории |
| 3 месяца | февраль–сентябрь 2024 | 8 | те же правила обучения |
| 6 месяцев | февраль–июнь 2024 | 5 | мало независимых временных точек |
| 12 месяцев | декабрь 2023 | 1 | только 12 месяцев истории; отдельный режим |

На 12 месяцах V3/V4 не оцениваются: нужный им годовой рост ещё не наблюдается. Отдельно проверяется `national_yoy_fallback`: расходы муниципалитета год назад, умноженные на национальный годовой коэффициент роста, известный в origin. Он не выдается за V3/V4. Prophet обучится на тех же 12 месяцах. Одна дата не позволяет убедительно оценить устойчивость годового прогноза; нужны более длинные муниципальные ряды. Во всех случаях горизонт означает точечный прогноз месяца t+h, а не сумму расходов за следующие h месяцев.

## Уже выполненный расчёт на всех 2016 рядах

| Метод | MAE, 1 месяц | MAE, 3 месяца | MAE, 6 месяцев | MAE, 12 месяцев |

| Национальный резервный метод | — | — | — | 1416.12 |
| Prophet, три варианта | только выборка 100 | только выборка 100 | только выборка 100 | только выборка 100 |

Единицы MAE — рубли в масштабе исходного показателя. По этим расширенным окнам V3-hedge лучше V4. Это исследовательские результаты на уже изучавшейся истории; они не являются независимым закрытым тестом. Результаты 400 рядов хранятся отдельно и не сравниваются с MAE на 2016 рядах.

Выходы: `metrics.csv` (MAE/R²/wMAPE), `metrics_by_origin.csv` (каждая дата), `comparisons.csv` (изменение MAE против каждого варианта Prophet), `selected_series.csv`, прогнозы и manifest. При частично отсутствующих прогнозах программа завершится ошибкой, вместо удаления неудачных строк из оценки. Пустой comparisons в диагностическом запуске означает, что сравнения с Prophet ещё нет.

## Пересборка отчёта

После агрегирования результатов: установить `requirements-report.txt` и выполнить `python benchmarks/build_verified_report.py --font-dir /usr/share/fonts/truetype/dejavu` (либо указать свой каталог DejaVu Sans). Команда создаёт согласованные Markdown и PDF.

На h=12 вариант с месячными индикаторами дал крайне неустойчивую экстраполяцию. Она сохранена без удаления выбросов; этот результат на 12 наблюдениях не является доказательством общей непригодности Prophet. Сравнение на более длинной истории остаётся необходимым.
