# Официальные ID и проверка транспортных связей, 7 октября 2026

## Что подтверждено

Полученный `hackathonlicence.zip` содержит 303126 строк расходов для 2190 territory_id. Среди них 2016 территорий имеют полную историю итоговой категории за январь 2023 - декабрь 2024. Все 2016 рядов **в точности совпали по всем 24 значениям** с использованной ранее панелью, причём соответствие однозначное. Прежние MAE и сравнение с Prophet относятся к тем же наблюдениям.

Полные исторические значения используются здесь только для восстановления идентичности ID-less выгрузки. Это не предиктор модели, не способ онлайн-сопоставления новых территорий и не новая независимая проверка точности. Порядок рядов, run_id и прогнозы сохранены.

Найден и скачан версионный справочник СберИндекса `t_dict_municipal_districts.xlsx`: 3101 версия территорий. По правилу `year_from <= year < year_to` построены отдельные соответствия для 2023 и 2024 годов. Все 2016 рядов получили официальный ID, регион и ОКТМО. Панель охватывает 73 региона. Все 107 рядов с повторяющимися названиями теперь имеют однозначную территориальную привязку.

В справочнике на 2024 год 2015 названий точно совпадают с публичной выгрузкой. Для territory_id=2454 название выгрузки содержит «Александровский муниципальный округ», а справочник - «муниципальный округ № 75», Санкт-Петербург. Оба названия сохранены отдельно, ID не подменён. В версии 2023 года различий названий 79: версии разных лет не смешиваются. Справочник описывает территориальные атрибуты; историческая доступность самих публикаций отдельно не восстановлена.

Рабочий исторический экспорт `outputs/operational/forecast_202412.csv.gz` теперь содержит territory_id, регион, ОКТМО и официальное название. Проверено, что все 8064 численных прогноза остались в точности прежними. Это пример из декабря 2024 года, а не прогноз на текущую дату.

## Эксперимент с соседними территориями

До вычисления результатов зафиксирован `config/graph_warning.json`. Используются восемь ближайших автодорожных соседей среди оцениваемых 2016 территорий, вес - обратное расстояние с нормировкой. Исходные связи симметризованы, самосвязи исключены. Получилось 16034 направленных ребра; 10 территорий не имеют автодорожных соседей в этой панели и получают нулевые соседские признаки с отдельным индикатором отсутствия связей.

К прежним признакам добавлены взвешенные сигналы jump, slope и ранее подтверждённых событий соседей. Коэффициент регуляризации логистической модели сохранён: 0.03. Контроль - тот же граф с совместной случайной перестановкой ID узлов, seed=47. Он сохраняет структуру и веса, но разрушает географическое соответствие. Одна перестановка - диагностический контроль, не статистический тест значимости.

Метки, месяцы, обучение на созревших событиях и бюджеты предупреждений совпадают с предыдущей проверкой. Метрики jump и logistic_base воспроизведены численно. Основной бюджет - 40 территорий в месяц (около 2%); результаты для 1% и 5% также опубликованы. Временные признаки проверены на неизменность при обрезании будущего.

| Задача | Метод | AP | Precision при 2% | Recall |
|---|---|---:|---:|---:|
| Обнаружение | jump | 0.4065 | 0.4500 | 0.3774 |
| Обнаружение | logistic_base | 0.4655 | 0.5450 | 0.4570 |
| Обнаружение | logistic_graph | 0.4657 | 0.5250 | 0.4403 |
| Обнаружение | случайно переставленный граф | 0.4593 | 0.5350 | 0.4486 |
| Обнаружение | только соседский jump | 0.0337 | 0.0575 | 0.0482 |
| Упреждение | jump | 0.0552 | 0.1050 | 0.1280 |
| Упреждение | logistic_base | 0.0264 | 0.0300 | 0.0366 |
| Упреждение | logistic_graph | 0.0266 | 0.0300 | 0.0366 |
| Упреждение | случайно переставленный граф | 0.0288 | 0.0550 | 0.0671 |
| Упреждение | только соседский jump | 0.0184 | 0.0200 | 0.0244 |

**Решение: транспортные признаки не включать в основной детектор.** При обнаружении число верных сигналов упало с 218 до 210 из 400; для упреждения осталось 6 из 200. Небольшое увеличение AP не даёт практически полезного улучшения при заданном бюджете. Реальный граф не показал убедительного преимущества перед контрольной перестановкой. При упреждении он предупредил 2 из 30 отдельных событий с полным окном наблюдения, тогда как прежний jump - 7 из 30. Повторные сигналы одному событию не считаются независимыми событиями.

Граф отражает расстояния **на 31 декабря 2024 года**. Его доступность и состояние на более ранние даты не подтверждены. Поэтому все эти результаты - исследовательская диагностика на статическом графе, даже несмотря на причинное построение динамических признаков. Индекс доступности рынков за 2024 год не включён в предикторы. Новые параметры по этим результатам не подбирались; основной прогноз V3-hedge не менялся.

## Воспроизведение и файлы

Установить `requirements-graph.txt`. Сохранить три Parquet-файла и описание архива под именем `dataset_description.pdf` в `data/raw/hackathon/`. Там же разместить `t_dict_municipal_districts.xlsx`. Пять прежних CSV остаются в `data/raw/` для проверки соответствия старой панели.

```bash
python -m unittest discover -s tests -p test_municipal_graph.py
python benchmarks/graph_warning.py
python benchmarks/attach_territory_metadata.py
python benchmarks/forecast_operational.py
```

Четыре теста проверяют сопоставление переставленных строк, отказ при неоднозначности, симметрию связей, поведение изолированных узлов, отсутствие влияния будущих значений, отсутствие самосвязей после перестановки и исключённую правую границу действия версии справочника.

`outputs/graph_warning/` содержит `identity_map.csv.gz`, `territory_map_2023.csv.gz`, `territory_map_2024.csv.gz`, `neighbors.csv.gz`, общие и помесячные метрики, audit.json и metadata_audit.json. Полные строки эксперимента `pairs.csv.gz` сохраняются при запуске локально; они не включены в Git. Аудит фиксирует SHA-256 данных и кода, версии пакетов и ограничения. Данные представлены по исходной категории «Все категории»; суммировать пять частных категорий вместо неё нельзя.
